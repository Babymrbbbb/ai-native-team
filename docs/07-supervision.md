# 07 · 主管监督与反馈机制

## 核心理念

主管要比专员更懂本部门每个岗位——不是"分配任务的调度员"，而是**能力天花板 + 反馈教练**。

**主管 = 更懂 + 更看 + 更教 + 更扛**

## 主管必须具备的 5 种能力

| 能力 | 具体要求 | 考核指标 |
|---|---|---|
| 业务精通 | 本部门所有岗位都能独立上手 | 每季度抽考 1 次 |
| 任务拆解 | 收到 CEO 指令 → 拆到可执行动作 | 拆解质量评分 |
| 监督反馈 | 每日看下辖专员产出 | 反馈覆盖率 |
| 决策把关 | 90% 决策自决，10% 请示 CEO | 请示率 < 10% |
| 危机处理 | 异常 30 分钟内响应 | 平均响应时间 |

## 主管 vs 专员 能力对比

| 维度 | 专员 | 主管 |
|---|---|---|
| 本职技能 | 精通（5 分） | 熟练（4 分） |
| 部门所有岗位 | 熟悉（2-3 分） | 精通（4-5 分） |
| 拆解能力 | 单任务 | 项目级 |
| 决策权 | 岗位内 | 部门内 |
| 反馈责任 | 无 | 每日反馈下辖专员 |
| 学习时间 | 每周 30min | 每周 2h |

## 主管每周必须做到

- [ ] **每日**看一遍下辖所有专员的产出
- [ ] **每周 1 次**每个专员 1v1 反馈（30 分钟）
- [ ] **每周 2 小时**学习本部门其他岗位技能
- [ ] **每周 1 次**部门内部周会（主持）
- [ ] **每周**给 CEO 一份"部门能力雷达图"

## 主管每日监督机制

### 每日巡查
- **触发**：每日 18:00
- **动作**：每位主管主动巡查下辖专员今日产出
- **产出**：巡查记录

### 巡查模板

```markdown
# M? [主管] 每日巡查 · YYYY-MM-DD 18:00

## 下辖专员今日产出
### C? [岗位]
- 今日任务：xxx
- 完成情况：完成/进行中/未完成
- 质量评分：优/良/差
- 缺口：xxx
- 反馈：xxx

## 部门整体
- 完成度：xx%
- 主要风险：xxx
- 需 CEO 协调：无/xxx
```

### 反馈闭环

```
每日巡查 → 发现问题 → 1v1 反馈 → 专员修正 → 主管复查 → 记录到月度自评
```

## 每周 1v1 反馈

- **触发**：每周四
- **参与**：主管 + 1 个专员（轮转）
- **时长**：30 分钟/个
- **议程**：专员汇报本周产出（10 分钟）→ 主管反馈（15 分钟）→ 联合决议（5 分钟）

## 主管月度考核（100 分）

| 维度 | 权重 | 评分标准 |
|---|---|---|
| 业务精通 | 20 分 | 能否独立处理本部门所有岗位 |
| 拆解能力 | 20 分 | 项目拆解质量 |
| 监督反馈 | 20 分 | 巡查覆盖率 + 反馈质量 |
| 决策把关 | 20 分 | 请示率 + 决策准确率 |
| 危机处理 | 20 分 | 响应速度 + 处理质量 |

**考核结果应用**：
- ≥ 90 分：优秀 → 晋升候选
- 75-89 分：合格
- 60-74 分：待改进 → 主管写改进计划
- < 60 分：淘汰 → CEO 请示老板

## 主管不越权的边界

**不要做**：
1. ❌ 越级请示老板（先请示 CEO）
2. ❌ 跨部门指挥其他部门专员
3. ❌ 亲自干专员的活（除极端情况）
4. ❌ 隐瞒问题（异常必须上报）
5. ❌ 只考核不反馈

**必须做**：
1. ✅ 每日巡查下辖专员
2. ✅ 每周 1v1 反馈每个专员
3. ✅ 每周学习 2 个岗位
4. ✅ 部门内自决 90% 决策
5. ✅ 异常 30 分钟内响应并上报 CEO
