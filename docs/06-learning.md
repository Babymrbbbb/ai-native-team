# 06 · 员工自主学习机制

## 核心理念

**学习专员只是"知识源"，不是"知识灌输"。**

原则：**自主学习 + 任务驱动 + 定期复盘** 三条腿走路。

## 学习机制全景

```
【知识源层】
├─ 学习专员（横向，主动选料+分发）
├─ 老板贴链接（事件驱动）
├─ 主管主动搜索（自主学习）

【消化层】
├─ 每日学习日志（5 分钟，个人）
├─ 每周主管技能自评（30 分钟）
├─ 每月岗位自评（60 分钟）

【应用层】
├─ 任务驱动学习（遇到问题 → 定向学习 → 更新技能）
├─ 学习 → SOP 更新 → 岗位卡升级

【沉淀层】
├─ 岗位技能地图（个人）
├─ 部门知识地图（部门）
├─ 全公司知识地图（学习专员维护）
```

## 每日学习日志（5 分钟，个人）

```markdown
# [岗位名] 学习日志 · YYYY-MM-DD

## 今日学到的一件事
- xxx

## 用到了哪个技能/工具
- xxx

## 遇到的知识缺口
- xxx

## 明日学习计划（5 分钟）
- xxx
```

规则：每个岗位每天一条，不强制但鼓励；主管每天扫读；学习专员每周日汇总共性缺口。

## 每周技能自评（30 分钟）

```markdown
# [岗位名] 技能自评 · YYYY-MM-DD

## 本周产出
- [任务 1] → [质量]：优/良/差

## 使用的技能/工具
- [技能 1]：熟练度 [1-5 分]

## 知识缺口
- [缺口 1]：影响 xxx

## 下周学习计划
- [计划 1]（30 分钟）
```

## 每月岗位自评（60 分钟）

流程：
1. 专员自评（20 分钟）：本月产出/技能/成长/缺口
2. 主管评价（20 分钟）：能力评估/岗位匹配度/成长潜力
3. 联合决议（20 分钟）：是否调整职责/升级技能/新增合并岗位/新学习资源

## 任务驱动学习（遇到不会的立刻学）

```
1. 专员记录问题
2. 尝试自主搜索
3. 无法解决 → 升级主管
4. 主管也解决不了 → 触发学习专员
5. 学习专员学习后 → 更新 SOP → 通知全公司
```

## 学习专员核心职责（横向）

每周任务：
1. **选料**（周一）：选 3-5 个高质量内容
2. **拆解**（周二/三）：归属判定 + SOP 提炼
3. **分发**（周日）：定向分发到对应部门
4. **复盘**（周日）：读所有岗位学习日志，找共性缺口

## 技能成熟度模型

| 阶段 | 熟练度 | 表现 | 主管期望 |
|---|---|---|---|
| 新手 | 1 分 | 需要手把手教 | 允许出错 |
| 熟悉 | 2-3 分 | 独立完成常规任务 | 少量指导 |
| 熟练 | 4 分 | 独立处理复杂任务 | 无需指导 |
| 专家 | 5 分 | 能指导新人 / 创新方法 | 承担更多 |

## 成长路径与晋升

| 阶段 | 岗位 | 熟练度要求 | 时间 |
|---|---|---|---|
| 入职 | 专员 | 1-2 分 | 第 1-2 月 |
| 独立 | 专员 | 3 分 | 第 3-6 月 |
| 熟练 | 高级专员 | 4 分 | 第 6-12 月 |
| 专家 | 主管候选 | 5 分 | 12 月+ |

晋升触发：连续 3 个月自评 A + 主管推荐 + CEO 评估 + 请示老板。
淘汰触发：连续 3 个月自评 C + 主管建议 + CEO 评估 + 请示老板。

## 学习纪律

1. 不强制打卡：学习日志不强制，但主管每周检查
2. 不设惩罚：缺日志不罚款，但影响月度评分
3. 鼓励主动：主动学习者优先获得新任务/晋升
4. 任务驱动优先：遇到问题立即学，比定期学习更实用
5. 知识不孤岛：学到的东西必沉淀到 SOP/岗位卡
6. 主管带头学：主管自己也要写学习日志
