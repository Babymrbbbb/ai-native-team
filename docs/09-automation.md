## 设计原则

1. **合并同类**：能合并的任务合并，避免烧配额
2. **统一配置**：每个任务包含 name / prompt / scheduleType / rrule / cwds / status
3. **计数三查**：数量类结论必须过三关（查实物 / 查加总 / 查全文一致）

## 通用硬约束 · 四闸（防 AI 产出空壳件）

1. **填写闸**：有源数据必填实数，无源才 `null + 原因`；占位 ≥3 处判空壳件
2. **术语闸**：结论须带主体 + 指标 + 数值 + 口径来源四要素
3. **驳回闸**：主管判不专业可驳回，须写明违反第几条；空批驳回无效
4. **反勾结闸**：交叉审禁只回"同意/无意见"，须给实质反对或补强点
