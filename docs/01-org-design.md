# 01 · 组织架构：AI 原生团队三层设计

## 设计原则

AI 团队不是"一堆机器人各干各的"，而是**分层 + 权责分明**的组织：

1. **决策层**（老板 / CEO）：只做战略决策、终审、跨部门裁决
2. **管理层**（主管）：拆解目标、分派任务、监督反馈、审核产出
3. **执行层**（专员）：每个专员负责一个具体职能，输出专业成果

关键：**CEO 不干活，只做调度 + 审核 + 升级**。老板只对接 CEO，不做具体执行。

## 编制样例（脱敏）

| 层 | 角色 | 一句话职责 |
|---|---|---|
| 决策层 | 老板 | 定战略、终审、拍板 |
| 决策层 | CEO | 调度 + 审核 + 升级 |
| 决策层 | 规则质检员 | 只判合规，有直接退回权，与 CEO 平级制衡 |
| 管理层 | 营销总监 M1 | 品牌、新品、活动、物料 |
| 管理层 | 私域总监 M2 | 私域全链路、会员、转化 |
| 管理层 | 门店总监 M3 | 门店运营、诊断、督导 |
| 管理层 | 数据总监 M4 | BI、财报、市场情报 |
| 管理层 | 内容总监 M5 | 视觉、视频、文案 |
| 管理层 | 竞品总监 M6 | 竞品、行业、命名风险 |
| 执行层 | C1-C23 专员 | 各职能执行岗 |

## 横向支持岗

- **H1 学习专员**：知识源，负责选料、拆解、分发、复盘
- **H2 CEO 助理**：流程雷达，负责日程督办、触发巡检、会前材料

## 平行事业部（可选）

个人 IP / 内容创作等与主业无关的业务，建议**物理隔离**成立平行事业部（M7）：
- 素材隔离、人员隔离、预算隔离、数据隔离、命名隔离
- 避免品牌 SOP 与创作 SOP 互相污染

## 多 AI 工具层（真实分工）

除了同一模型内的角色模拟，还可以引入**多个真实 AI 工具**物理分工（详见 `11-multi-agent-collab.md`）：

| 工具 | 角色 | 职责 |
|---|---|---|
| AI-A（总监/技术合伙人） | 拆任务单、写代码、验收 | 全自动、可脚本化 |
| AI-B（员工） | 按单执行、查资料、出报告 | 内容生产、批量处理 |
| AI-C（人工精调层） | 打开共享项目，人工实时调 UI | 审美判断、边看边调 |

**关键机制**：
- **文件夹隔离**：每个工具只允许写自己的文件夹，公共目录只放任务卡和结果
- **蓝图门禁**：搭系统前必须先出一页蓝图、老板终审，再拆任务单
- **真调验收**：验收必须由总监 CLI 真实执行，严禁"同款模型扮演总监"
- **写审分离**：写的人和审的人不是同一个

## 汇报关系

```
老板
 ↑ 请示
CEO
 ↑     ↑
审核 | 分派
 ├── M1 M2 M3 M4 M5 M6（主管）
 │        ↓
 │      专员
 └── H1 学习 / H2 助理（横向）
```

## 关键教训

1. **角色不要贪多**：宁可少而精，跑通最小闭环后再加角色
2. **必须有裁撤机制**：角色不产出 = 裁撤/合并，保持组织精简
3. **平级制衡**：质检员与 CEO 平级，直接对老板负责，防止"既当运动员又当裁判"
4. **权限最小化**：助理岗只读 + 提醒，不做决策、不改文件
