# 08 · 决策边界与分层审批

## 核心理念

很多事情不需要过问老板，团队内部能自决就自决。

**原则：明确边界、层级分明、请示有据、事后透明**

## 决策三层边界

```
【第 1 层】专员岗位内决策
  ↓ 决策权在专员本人
  ↓ 无需请示主管/CEO/老板

【第 2 层】部门内决策
  ↓ 主管自主决策
  ↓ 无需请示 CEO/老板

【第 3 层】跨部门/战略级决策
  ↓ CEO 决策或请示老板
  ↓ 按预算/影响/风险分档
```

## 专员岗位内决策（无需请示）

| 决策类型 | 举例 | 决策权 |
|---|---|---|
| 产出格式 | 报告用 md 还是 ppt | 专员自决 |
| 工具选择 | 用哪个 AI 工具 | 专员自决 |
| 执行顺序 | 3 个步骤先做哪个 | 专员自决 |
| 文案措辞 | 具体文字用词 | 专员自决 |
| 视觉风格 | 图片的具体构图 | 专员自决 |
| 数据呈现 | 图表类型选择 | 专员自决 |
| 个人时间分配 | 1 小时内时间怎么排 | 专员自决 |
| 临时性问题解决 | 卡点自己尝试 30 分钟 | 专员自决（超 30min 上报） |

## 专员必须请示主管的情况

| 情形 | 请示对象 |
|---|---|
| 任务超时 | 主管 |
| 资源不够（缺工具/缺数据/缺权限） | 主管 |
| 跨专员依赖 | 主管协调 |
| 跨部门依赖 | 主管 + CEO |
| 战略不明确 | 主管 + CEO |
| 涉及外部发布/承诺 | 主管 → CEO → 老板 |
| 涉及预算 | 按边界 |

## 部门内决策（主管自决，无需请示 CEO）

| 决策类型 | 举例 |
|---|---|
| 部门任务分配 | 谁做哪个动作 |
| 部门内优先级 | 3 个任务哪个先做 |
| 部门内资源调配 | 谁帮谁 |
| 部门内人员指导 | 具体怎么教 |
| 部门内工具使用 | 用哪个工具 |
| 部门内数据口径 | 数据怎么算 |
| 部门内流程优化 | 优化哪个环节 |

## 主管必须请示 CEO 的情况

- 涉及跨部门协调
- 涉及预算 > 阈值
- 涉及品牌口径重大变化
- 涉及人事（招/裁/晋升）
- 涉及跨部门战略议题
- 部门内冲突主管无法调解
- 涉及对外承诺
- 部门内连续 2 周绩效不达标

## 主管请示率考核

**目标**：主管请示率 < 10%
- 意思：主管每周 10 件事，最多 1 件需要请示 CEO
- 请示率 > 10% → 主管能力不达标
- 连续 2 周请示率 > 20% → 主管需要进修或淘汰

## CEO 决策与请示老板的边界

### CEO 自决清单

| 决策类型 | 举例 |
|---|---|
| 单部门内方案 | 单部门任务分派 |
| 跨 2-3 部门协调 | 跨部门协作 |
| 预算 ≤ 1 万 | 小预算自主 |
| 预算 1-5 万 | CEO 决策 + 事后报备老板 |
| 战略方向微调 | 战术级调整 |
| 员工评价 | 日常评价 |
| 项目拆解 | 项目级拆解 |

### CEO 必须请示老板的情况

| 情形 | 原因 |
|---|---|
| 预算 > 5 万 | 大额支出 |
| 预算 > 10 万 | 重大支出 |
| 跨 4+ 部门议题 | 影响面广 |
| 人事决策（招/裁/晋升主管） | 组织架构变动 |
| 战略方向变化 | 品牌/业务方向 |
| 对外重大承诺 | 合作方签约 |
| 涉及风险承受 | 高风险决策 |

## 决策快速判断表

```
【收到任务/需求】
    ↓
这是单岗位内的小事吗？
    ├─ 是 → 专员自决
    └─ 否 ↓
这是单部门内的事吗？
    ├─ 是 → 主管自决
    └─ 否 ↓
这涉及预算 > 1 万吗？
    ├─ ≤ 1 万 → CEO 自决
    ├─ 1-5 万 → CEO 决策 + 事后报备
    └─ > 5 万 ↓
涉及跨 4+ 部门/人事/战略/对外承诺/高风险吗？
    ├─ 是 → CEO 请示老板
    └─ 否 → CEO 决策 + 事后报备
```

## 决策审计（每月）

每月 CEO 复盘一次决策记录：
- 决策总数
- 正确率
- 错误决策复盘
- 请示边界是否需要调整

## 内部决策纪律

1. **不越级**：专员不越主管直接请示 CEO
2. **不绕过**：主管不越 CEO 直接请示老板
3. **不隐瞒**：任何问题不藏着，主动上报
4. **不推诿**：决策失误要承认，不甩锅
5. **不猜**：不确定就上报，不擅自决定
6. **有依据**：每个决策都要有依据记录
7. **有复盘**：重要决策必须复盘
