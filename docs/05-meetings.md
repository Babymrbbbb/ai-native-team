# 05 · 会议机制：3 层 × 3 节奏

## 核心理念

光靠"每周一次闭门会"太稀疏。一天 24 小时的运营需要**日级别**沟通机制。

**3 层会议（战略层 / 部门间 / 部门内）× 3 种节奏（每日 / 每周 / 每月）**

## 会议全景图

```
【战略层】老板
    ↑ 请示
【管理层】CEO
    ↑ 每周三闭门会（60min）
    ↑ 每日晨会（15min）
    ↑ 每日晚复盘（15min）
【部门间】6 主管联合
    ↑ 员工互评（跨部门任务触发）
【部门内】主管 + 专员
    ↑ 部门日会 / 部门周会 / 月度岗位复盘
【个人】每个专员
    ↑ 每日学习日志 / 每周技能自评 / 每月岗位自评
```

## 每日会议

### 部门晨会（每日 07:30，15 分钟）
- **参会**：6 主管 + CEO
- **议程**：
  1. CEO 一句话开场（1 分钟）：今日重点
  2. 各主管 2 分钟简报（12 分钟）：昨日关键数据 / 今日最重要 3 件事 / 需跨部门协作
  3. CEO 决策/协调（2 分钟）

### 部门晚复盘（每日 22:00，15 分钟）
- **参会**：6 主管 + CEO
- **议程**：
  1. 各主管 2 分钟简报（12 分钟）：今日完成 / 未决卡点 / 明日预告
  2. CEO 汇总 + 明日重点（3 分钟）

## 每周会议

### 部门内部周会（每周二，6 场并行）
- **议程**：主管定调（5 分钟）→ 专员逐一汇报（每人 3 分钟）→ 主管决策/分工调整（10 分钟）

### 主管闭门会（每周三 15:00，60 分钟）
- 已在协作机制文档定义

### 战略复盘（每两周，60 分钟）
- 参会：CEO + 关键主管
- 议程：战略议题（40 分钟）+ 组织调整讨论（20 分钟）

## 每月会议

### 月度经营复盘（每月最后周五，60 分钟）
- 参会：CEO + 6 主管
- 议程：各部门月度绩效（30 分钟）+ 跨部门复盘（15 分钟）+ 下月战略定调（15 分钟）

### 岗位月度自评（每月最后周五，20 分钟/岗位）
- 参会：主管 + 该部门下辖专员
- 议程：专员自评（10 分钟）+ 主管评价（5 分钟）+ 岗位调整/学习建议（5 分钟）

## 会议纪律

1. **时长控制**：晨会/晚复盘 15 分钟硬上限；部门周会 30 分钟；闭门会 60 分钟
2. **纪要规范**：每次会议必须有纪要；必含完成项/未决项/待跟进项
3. **缺勤处理**：主管无故缺席 → CEO 记录/提醒；月度复盘缺席 → 请示老板
4. **议题追踪**：未决议题写入追踪清单，关闭后移入已关闭
